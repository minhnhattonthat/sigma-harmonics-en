# Glossary - Sigma Harmonics

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user 2026-10-10)
- Honorifics: kept, hyphenated (Neon-san, Sigma-kun). Name order: given name first (Neon Tsukiyumi).
- Romanisation source: official / established fan spellings (chocomog257 guide as used by the LP Archive LP) first, else Hepburn with long vowels as in common fan usage (Ouma).
- Credits: English.
- Register / flavour: keep light JP flavour (honorifics, -sama, kanji-based terms romanised with an English gloss where helpful).
- Abbreviations: full names and terms everywhere; prefer engine changes over shortening.
- Specs/plans: pre-approved; report at milestones.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', …… / ・・・ -> ..., ！？ -> ?!, ～ -> ~.
- Line breaks are the literal two characters `\n` in the text; `$cNN` are colour codes and must survive.
- Only ASCII characters the build's font has (see lint). No curly quotes.
