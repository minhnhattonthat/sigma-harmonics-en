# Glossary - Sigma Harmonics

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
Seeded from the game's own term list (string table 04741, term + kana reading) and the fan guide by chocomog257.

## Rulings (asked of the user 2026-10-10)
- Honorifics: kept, hyphenated (Neon-san, Sigma-kun, Obaba-sama). Name order: given name first (Neon Tsukiyumi).
- Romanisation source: official / established fan spellings first, else Hepburn with doubled vowels as in fan usage (Ouma, Yuu, Fuyou, Kujou).
- Credits: English.
- Register / flavour: keep light JP flavour; terms of the game's lore get English names below, a few stay romanised.
- Abbreviations: full names and terms everywhere; prefer engine changes over shortening.
- Specs/plans: pre-approved; report at milestones.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', 【term】 -> [term] (keep the brackets: the game uses them for key terms),
  《term》 -> <term>, …… / ・・・ -> ..., ！？ / ？！ -> ?!, ～ -> ~, ー (long stretch) -> letters ("Kyaaa!").
- Full-width digits/letters become ASCII (１８時 -> 6 PM / 18:00, Ｑ．Ｅ．Ｄ． -> Q.E.D.).
- `$cNN ... $c00` are colour codes: keep every one, in order, around the matching English words.
- Dialogue is auto-wrapped by the build (3 lines x 180 px, ~26 chars/line). Don't write `\n` in dialogue.
- Plain ASCII only. No curly quotes, no em dash (use --).
