# Style reference - Sigma Harmonics

## Voices
| Character | Japanese markers | English voice |
|---|---|---|
| Sigma | 僕, calm, analytical, だね/かい | Composed, precise, a little dry; long logical sentences; "Q.E.D." Never slangy. Inner voice the same, quieter. |
| Neon (default) | ねぇシグマ, だよ, でしょ？, ～ | Bright, warm, casual teenage girl: "Hey, Sigma!", "That's so weird!" |
| Neon, terse costume | 疑問, 了解, 然し乍ら, ではでは, clipped kanji | Clipped, formal-robotic: "Query.", "Acknowledged.", "Nevertheless, understood." Drop articles where JP drops particles. |
| Neon, gyaru costume | じゃん, ややや, っしょ | Slangy and breezy: "Whoa whoa, that's so weird." |
| Neon, haughty costume | なさい, のよ, でしょうね！ | Imperious young lady: "Reason it out properly!", "Don't tell me that's your conclusion!" |
| Neon, other costumes | verbal tics (～ふう, ～にゃ...) | Keep the tic as a tic: "Who-fuu?". Never merge two voices into one. |
| Butler | ございます, いたしました | Stiff and formal: "No record exists, sir." |
| Ouma / dark voices ($c01...) | 貴様, 消えろ | Menacing, archaic: "Begone." "What are you?" |
| System / tutorial | です/ます, 【】 terms | Plain instructional English, imperative: "Select [Sound Search] from the menu." |
